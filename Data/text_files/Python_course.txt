# Python Programming Course

## 1. Introduction to Python

Python is a high-level, interpreted programming language known for its simple syntax and readability. It is widely used in web development, automation, data science, machine learning, artificial intelligence, and backend development.

Python supports multiple programming paradigms, including procedural, object-oriented, and functional programming.

### Key Features
- Simple and readable syntax
- Dynamic typing
- Large standard library
- Cross-platform compatibility
- Extensive third-party package ecosystem

### Example

```python
name = "Sharad"
age = 24

print(f"My name is {name} and I am {age} years old.")
```

## 2. Python Variables and Data Types

Variables store data that can be accessed and modified during program execution. Python determines the type of a variable dynamically.

### Common Data Types
- int: Integer values such as 10 and 100
- float: Decimal values such as 3.14
- str: Text values such as "Python"
- bool: Boolean values True and False
- list: Ordered and mutable collection
- tuple: Ordered and immutable collection
- dict: Key-value collection
- set: Collection of unique elements

### Example

```python
name = "Python"
version = 3.13
is_popular = True
topics = ["variables", "functions", "classes"]

print(type(name))
print(type(version))
print(type(is_popular))
print(topics)
```

## 3. Conditional Statements

Conditional statements allow a program to make decisions based on conditions.

Python uses if, elif, and else to control program execution.

### Example

```python
marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
else:
    print("Needs improvement")
```

## 4. Loops in Python

Loops execute a block of code repeatedly. Python provides for loops and while loops.

A for loop is commonly used to iterate over a sequence. A while loop continues as long as its condition remains true.

### Example

```python
for number in range(1, 6):
    print(number)

count = 1

while count <= 3:
    print("Python practice")
    count += 1
```

## 5. Functions

A function is a reusable block of code designed to perform a particular task. Functions improve modularity, readability, and maintainability.

Functions are defined using the def keyword. They can accept parameters and return values.

### Example

```python
def calculate_sum(a, b):
    return a + b

result = calculate_sum(10, 20)
print(result)
```

## 6. Lists, Tuples, and Dictionaries

Lists are mutable collections that support indexing and slicing. Tuples are immutable sequences. Dictionaries store values using unique keys.

These data structures are essential for organizing and processing information.

### Example

```python
skills = ["Python", "SQL", "FastAPI"]
student = ("Sharad", 24)
employee = {
    "name": "Sharad",
    "role": "Software Engineer",
    "department": "Backend"
}

print(skills[0])

```

## 7. Object-Oriented Programming

Object-oriented programming organizes software around classes and objects.

A class defines attributes and methods. An object is an instance of a class.

Important OOP concepts include encapsulation, inheritance, polymorphism, and abstraction.

### Example

```python
class Employee:
    def __init__(self, name, department):
        self.name = name
        self.department = department

    def display_details(self):
        return f"{self.name} works in {self.department}"

employee = Employee("Sharad", "Backend Development")
print(employee.display_details())
```

## 8. Exception Handling

Exception handling allows applications to respond to runtime errors without terminating unexpectedly.

Python provides try, except, else, and finally blocks.

### Example

```python
try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(result)
except ValueError:
    print("Please enter a valid integer.")
except ZeroDivisionError:
    print("Division by zero is not allowed.")
finally:
    print("Execution completed.")
```

## 9. File Handling

File handling enables programs to read and write persistent data. Python provides functions such as open(), read(), write(), and close().

The with statement is recommended because it automatically closes the file after the operation.

### Example

```python
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("Learning Python file handling.")

with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

## 12. Introduction to Artificial Intelligence

Artificial intelligence enables computer systems to perform tasks that typically require human intelligence, such as language understanding, reasoning, classification, and content generation.

Machine learning is a branch of AI in which models learn patterns from data. Deep learning uses neural networks to learn complex representations.

Large Language Models (LLMs) are trained to process and generate text and other supported forms of content.

## 13. Introduction to Retrieval-Augmented Generation

Retrieval-Augmented Generation, commonly called RAG, combines information retrieval with language generation.

A RAG application retrieves relevant information from an external knowledge source and provides that information as context to a language model.

RAG is useful when an application needs to answer questions using private documents, technical manuals, company policies, or domain-specific knowledge.

### Basic RAG Workflow

1. Load source documents.
2. Split documents into smaller text chunks.
3. Generate embeddings for the chunks.
4. Store the embeddings in a vector database.
5. Retrieve relevant chunks when a user asks a question.
6. Provide the retrieved context to an LLM.
7. Generate an answer grounded in the retrieved information.

## 14. LangChain Document Data Structure

LangChain provides a Document class to represent text alongside associated metadata.

A Document typically contains page_content, metadata, and an optional id.

The page_content field stores the text. The metadata field stores information such as the filename, page number, category, or author.

### Example

```python
from langchain_core.documents import Document

document = Document(
    page_content="Python is a high-level programming language.",
    metadata={
        "source": "python_course.txt",
        "topic": "Introduction to Python",
        "category": "Programming"
    },
    id="python-001"
)

print(document.page_content)
print(document.metadata)
print(document.id)
```

Document objects can be passed between loaders, text splitters, retrievers, and other components of a RAG pipeline.
